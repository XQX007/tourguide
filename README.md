# TabFlow · 吉他谱动态阅读器

一个**本地运行**的吉他谱阅读器：上传吉他谱图片或 PDF，像 Songsterr 一样边看边弹。

当前版本聚焦“阅读与练习”，**不包含图片自动转六线谱（OMR）**；图片/PDF 会按原样显示，并叠加自动滚动、节拍器、A-B 循环、缩放/旋转等练习工具。

> 视频里的滚动谱是“单行横向滚动 + 黄色当前小节高亮”。本工具针对整页图片/PDF，用“**竖向逐行滚动 + 黄色当前行高亮带**”模拟同样的阅读效果；如果要完全做成单行横向 ticker，需要先把每行谱切出来。

---

## 快速开始

1. 双击 **`start.bat`**；
2. 浏览器会自动打开 `http://127.0.0.1:8765/`；
3. 把吉他谱图片或 PDF 拖进页面，或点“打开谱面”；
4. 按 **空格** 开始/暂停自动滚动。

> 请通过 `start.bat` 启动，不要直接双击 `index.html`。  
> PDF.js 的 worker 需要 HTTP 环境，`file://` 下 PDF 可能无法解析。

## 单行模式（实验）

打开：

```text
http://127.0.0.1:8765/single.html
```

或点首页右上角的 **“单行模式”**。

这个模式会：

1. 自动识别图片/PDF 里每一行六线谱（6 条横线）；
2. 把每一行裁出来，横向拼成一整条长谱；
3. 自动检测每一行里的小节线，用黄色高亮框标出当前小节；
4. 按 **BPM × 每小节拍数** 的速度，一小节一小节横向滚动。

可以调：

- **BPM**：每小节耗时 = 拍数 × 60 / BPM；
- **拍/小节**：2 / 3 / 4 / 6；
- **每小节宽度**：作为“没检测到小节线”时的兜底宽度；
- **循环**：到末尾回到开头。

> 识别依赖“每行正好 6 条横线”的六线谱；如果识别失败或拼接不对，先用整页阅读器。

## 功能

- 图片：JPG / PNG / WEBP / GIF
- PDF：多页解析、页面缩略图、点击跳页
- 自动滚动：速度 5–200 px/s，空格暂停/继续
- **逐行滚动**：每个节拍/每 N 拍滚动一行（40–240 px/行），速度由 BPM 决定
- **黄色高亮带**：当前行高亮、上下轻微压暗，模拟视频滚动谱的“当前小节”效果
- 节拍器：40–200 BPM，4/4 拍指示，预备拍 0/4/8
- A-B 循环：按当前滚动位置设置 A/B，自动滚动到 B 跳回 A
- 缩放：50%–200%
- 旋转：90° 步进
- 全屏
- 页面进度条、当前页高亮
- 拖拽上传、剪贴板粘贴图片
- 设置记忆：速度、BPM、预备拍、缩放

## 隐私

所有文件都在浏览器本地处理：

- 不会上传到服务器；
- 服务器只负责把 `index.html`、`app.js`、PDF.js 等静态文件发给浏览器；
- 关闭页面后，上传的谱面不会被保存。

---

## 已知限制

- 当前不做图片识别（OMR），不能把图片自动变成可播放的六线谱；
- PDF 解析依赖 PDF.js，极少数特殊字体/加密 PDF 可能显示异常；
- A-B 循环以“滚动比例”记录，缩放或旋转后仍按比例保留；
- 旋转 90° 时页面会按高度适配，特别长的谱可能需要再缩放；
- 浏览器需要支持 ES Modules、Web Audio、CSS zoom（推荐 Edge / Chrome）。

## 常见问题

**Q：双击 `start.bat` 后窗口一闪而过？**  
右键 `start.bat` → 以管理员身份运行，或在 PowerShell 中执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\server.ps1
```

**Q：端口被占用？**  
脚本会自动尝试 `8765–8789`，启动后看窗口里打印的地址。

**Q：PDF 一直转圈/报错？**  
确认是通过 `http://127.0.0.1:...` 打开的，而不是 `file://`；再刷新页面重试。

**Q：按空格没有滚动？**
- 看页面左下角是否提示“没有可滚动空间”。如果整页已经完整显示，放大（+）或打开多页 PDF 才会有滚动；
- 如果“预备拍”选了 4 或 8 拍，按空格后会先数拍再开始；想立即开始就选“无预备拍”；
- 在网址后加 `?debug=1`，页面右下角会显示 `scrollTop / max / clientH / scrollH`，方便排查。

**Q：怎么让滚动一行一行走？**
- 点底部的 **“逐行”** 按钮（默认就是逐行模式）；
- 设置 BPM（例如 80）、“每行高度”（例如 110 px/行）和“每几拍一行”（例如 2 拍/行）；
- 按空格，每 N 拍滚动一行，滚完一行停一下再滚下一行；
- 想恢复普通匀速滚动，再点一次“逐行”。

**Q：滚到末尾就停了？**
- 单页内容不够长时，滚到底会停，并提示“已到谱面末尾”；
- 想反复练这一页：滚到开头按 `A`，滚到末尾按 `B`，按 `L` 开启循环，就会自动跳回 A 重复；
- 想看更多行：打开多页 PDF，或换一张更高的谱图。

**Q：想部署到公网？**  
把整个目录作为静态站点部署即可；但要注意用户上传谱面的版权问题。当前版本没有后端，文件不会上传。
